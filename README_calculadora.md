# Calculadora

Calculadora simples feita em HTML, CSS e JavaScript, que roda direto no navegador — sem precisar instalar nada.

## O que ela faz

- Soma, subtrai, multiplica e divide
- Interface de botões parecida com a calculadora de celular
- Funciona 100% offline, direto no navegador

## Tecnologias usadas

HTML · CSS · JavaScript

## Como usar

Não precisa instalar nada nem digitar comando nenhum. Só duas formas simples:

**Opção 1 — Usar direto pela internet (mais fácil):**
 basta abrir o link da página no navegador do computador ou celular.

**Opção 2 — Usar no seu computador:**
1. Baixe o projeto clicando em "Code" → "Download ZIP" na página do repositório no GitHub, ou:
```bash
git clone https://github.com/beneditodossantosjoao027-cloud/calculadora.git
```
2. Abra a pasta baixada e dê duplo clique no arquivo `index.html`.
3. Ela vai abrir direto no seu navegador (Chrome, Edge, Firefox etc.) e já pode usar.

## Segurança

É uma página 100% local — não envia nenhum dado pela internet, não pede permissão nenhuma e não coleta nada do usuário.
